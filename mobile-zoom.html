如何保证「缩放不跳」

  • 缩放前先记录两指中点相对容器中心的坐标 c，以及起始比例 s0、起始平移 t0。
  • 每帧按 t = c − (c − t0) × (s / s0) 同步修正平移，让手指按住的像素始终停在原地。
  • transform-origin 固定为 center，避免原点变化导致的跳变。
  • 双指中点移动时用新的中点重算 c，所以两指一起移也能跟手。
  • 比例钳制在 1～4；缩到 1 时自动居中，不会留下空白边。

其它验收点

  • 边界：放大后拖动到边缘松手，0.25s 过渡吸附回边界内；1x 时 maxX/maxY 为 0，拖不出去。
  • 旋转屏幕：resize 时重新计算基准尺寸并保留 scale，只夹取平移，不重置状态。
  • touchmove 用 { passive:false } 并在双指 / 放大时 preventDefault()，页面不会跟着缩放。
