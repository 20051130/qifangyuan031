任务一 · 提示词工程师两轮迭代 · 让 AI 听懂需求

需求共 4 条：无缝循环、3.2 秒自动翻页且手动操作后不停止、圆点分页器可点击、初始效果 cube。下面是两轮提示词的完整记录。

🔁 第 1 轮提示词（初版，故意先按直觉写）
"帮我写一个 Swiper 11 的初始化配置，选择器 #wySw4：要能无缝循环，自动播放，切换动画 800 毫秒，有圆点分页器，效果用 cube。"

👇 第 1 轮配置的实际效果（能看出问题）：

天宫空间站

autoplay 简写 → 默认 3 秒，不是 3.2 秒

复兴号动车组

无 disableOnInteraction → 拖一下就停

C919 大飞机

pagination 无 el → 圆点没绑到容器

第 1 轮的 3 处问题（对照需求逐条核对发现的）：
① autoplay: true 只会开默认 3 秒间隔，写不出"3.2 秒"，必须用对象 { delay: 3200 }；
② 漏了 disableOnInteraction: false——Swiper 默认用户一拖动自动播放就永久停止，不满足"手动操作后不停止"；
③ pagination 没写 el，圆点渲染不到指定容器（需手动拖动才会发现停了）。
🔁 第 2 轮提示词（逐条编号，参数说到位）
"重写，仍用 Swiper 11、选择器 #wySw4，逐条满足：1 loop 无缝循环；2 autoplay 用对象写法，delay 精确为 3200 毫秒，并且用户手动拖动后自动播放不能停（disableOnInteraction: false）；3 圆点分页器渲染进指定容器，且可点击跳转；4 effect 初始为 'cube'；5 切换动画 800 毫秒。每行加中文注释。"

✅ 向 AI 追问后，用自己的话写下的结论

prev 的 transform 控制什么？控制"已经翻过去的上一张（左侧旧卡）"离场之后的造型——本页让它左移 58%、缩小到 0.78、绕屏幕平面转 -20°、半透明，像电影墙里靠边的一张海报。
next 的 transform 控制什么？控制"即将进场的下一张（右侧新卡）"出发时的造型——本页让它从右边一个 slide 宽度处、放大 1.15 倍出发，切换动画进行时逐渐回到正中间、恢复原始大小。

答辩抽问自答：① transform 里的百分号相对 slide 自身的宽度，不是容器宽度（z 值是像素）；② 现场把 rotate 改成 [0, 0, 20]，卡片会从"逆时针歪"变成"顺时针歪 20 度"，离场方向相反——已在本页实测。

✅ 答辩四连问 · 预设回答

1. 这段代码什么意思？keyboard 模块把 ← / → 键绑定到轮播的 slideNext / slidePrev 方法上；tabindex="0" 让容器能被点击聚焦，键盘事件才有目标。
2. AI 第一次给的哪里不对、你改了什么？AI 第一次没提 tabindex="0"，页面上按方向键完全没反应（控制台也不报错，是焦点问题不是 JS 错误）；查官方 keyboard 演示发现演示容器有 tabindex，补上就好了。
3. 新参数的作用？enabled 开关功能本身；onlyInViewport 限定"轮播滚出屏幕后不再吞键盘事件"，两个都为 true 才是体验正确的做法。
4. 现场把 delay 改成指定值并解释预期变化：把 autoplay.delay: 3200 改成 1000，预期：自动翻页间隔从 3.2 秒缩短为 1 秒，speed 800 不变所以动画本身快慢不变，只是停留时间变短；刷新后数拍子可验证。

📄 查看本页完整 JS 源码（可直接对照讲） 
<script>
  // ── 任务 1 的最终配置（抽成函数，供"销毁重建"复用） ──
  function makeSw4Config(fx) {
    return {
      loop: true,                                   // 无缝循环
      effect: fx,                                   // 当前效果，初始 'cube'
      speed: 800,                                   // 切换动画 800 毫秒
      autoplay: { delay: 3200, disableOnInteraction: false },  // 3.2 秒自动翻页，拖动后不停
      pagination: { el: '#wyPag4', clickable: true },          // 圆点分页器可点击
      keyboard: { enabled: true, onlyInViewport: true },       // 任务 3：键盘 ← → 控制
      creativeEffect: {                             // 任务 2：creative 电影墙参数
        prev: { shadow: true, translate: ['-58%', 0, -180],
                rotate: [0, 0, -20], scale: 0.78, opacity: 0.45 },
        next: { shadow: true, translate: ['100%', 0, 0],
                scale: 1.15, opacity: 0.4 }
      }
    };
  }
  // 初始效果为 cube（任务 1 要求）
  var wySw4 = new Swiper('#wySw4', makeSw4Config('cube'));

  // 7 个效果按钮：销毁旧实例 → 用新 effect 重建（动态换 effect 必须销毁重建）
  document.querySelectorAll('.wy-fx button').forEach(function(btn){
    btn.addEventListener('click', function(){
      document.querySelectorAll('.wy-fx button').forEach(function(b){
        b.classList.remove('wy-on');
      });
      btn.classList.add('wy-on');            // 高亮当前按钮
      wySw4.destroy(true, true);             // 清掉 Swiper 注入的样式，DOM 才干净
      wySw4 = new Swiper('#wySw4', makeSw4Config(btn.dataset.fx));  // 重建
    });
  });
</script>
