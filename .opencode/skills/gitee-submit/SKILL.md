# Gitee项目提交技能

此技能帮助用户将项目代码提交到Gitee远程仓库。

## 使用场景

- 用户要求提交项目到Gitee
- 用户要求推送到远程仓库
- 需要进行git commit和push操作

## 操作步骤

1. 检查是否已初始化git仓库（如果没有则初始化）
2. 添加所有文件到暂存区
3. 创建commit
4. 配置远程仓库地址
5. 推送到远程仓库

## 注意事项

- 确保gitee令牌已配置
- 确保远程仓库地址正确
- 推送前检查是否有冲突
